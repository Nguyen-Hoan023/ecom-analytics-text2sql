# Orchestration acceptance evidence

This folder contains a sanitized summary of local Astro/Airflow/Cosmos acceptance.

The acceptance record is based on owner-confirmed terminal and Airflow UI results, not a retained machine log export. Include exact run IDs only when they are available from preserved evidence.

Do not confuse a local image/DAG parse with a live pipeline run, host connectivity with container connectivity, or repeatability for one snapshot with a future freshness guarantee. Never store credentials, raw environment values, or customer rows here.

See [workflow acceptance](workflow-acceptance.md) for the recorded scope and [orchestration guide](../../orchestration/README.md) for current commands and runtime boundaries.
