# Generated Gold-mart charts

The PNGs in this directory are reproducible aggregate views of the local DuckDB Gold marts. They are generated by <code>analytics/visualization/generate_charts.py</code>; do not hand-edit the chart files.

## Regenerate

From the repository root, after source ingestion and a successful dbt build:

    uv run --project . python scripts/project.py charts

The generator opens DuckDB in read-only mode, checks that its required marts exist, and reconciles key totals before writing the images.

## Interpretation

- Amounts keep source units; no currency symbol is implied.
- Discount bands are descriptive groups, not a causal experiment.
- RFM risk is a recency heuristic at the documented historical snapshot, not a churn label.
- Market-basket results are not plotted as recommendations because pair counts are sparse.
